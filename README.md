#   Sistema de Oficina Mecânica

##  Autor
    Luciano Schuck
##  Data de Criação
    28/10/2026
##  Descrição
    Projeto desenvolvido em Python para
    cadastrar veículos, lançar serviços e
    gerenciar ordens de serviço em uma oficina
    mecânica.
##  Funcionalidades
    - Cadastrar veículos
    - Registrar serviços (Troca de óleo e Alinhamento)
    - Listar ordens de serviço
    - Calcular o valor do orçamento
    - Exibir o resumo da ordem de serviço
## Tecnologias
    - Python 3.x
